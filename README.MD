# Aquapoint

Web developing project.

## What is Aquapoint?

Aqua Point is a web application that allows users to find drinking fountains near them, not only to quench their thirst but also to share their opinions and experiences. With intuitive and practical features, this application aims to simplify and optimize the search for functional drinking fountains near the user.
The technologies used are diverse, encompassing various software tools and programming languages. In addition, Aqua Point aims to introduce new security features to ensure greater user protection and data privacy. The project will also explore distributed systems to improve scalability, reliability, and performance (using docker), as well as artificial intelligence (AI) to provide smarter features, enhance the user experience, and make finding drinking fountains more efficient.
